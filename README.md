# Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA).
The frontend of any applicatoin is arguably the most important aspect of any applicatoin as this is the entry point between the business and customer. It's important to create engaging user experiences while ensuring a robust and secure application. In the full-stack web app I developed, we utilized express and angular to build separate UIs intended to server separate users. For instance, our customers experience the app through the express framework which dynamically updates the html from the server before sending the rendered html page to the client for them to view and interact. This differs from the SPA I developed which utilized the angular framework to develop a dynamic single page allowing admins control over their app and the travel packages they offer. The SPA is a great choice for integrating a fast and responsive user experience because it forces the browser to render to the page which ultimatley improves loading speeds and interativity. Although these UIs vary in there frameworks, they work together to provide an efficient and robust environment for both customers and businesses using a derivation of Javascript, the programming language used for websites.

# Why did the backend use a NoSQL MongoDB database?
I used a NoSQL db because it improves query speeds, provides schema flexiblity, and efficiently scales horizontally allowing businesses to grow with their customer base.

# How is JSON different from Javascript and how does JSON tie together the frontend and backend development pieces?
JSON is simply a mechanism which allows components to share data via a regulated layout. This differs from Javascript because javascript is a programming language used to build apps and intended to give guidance on how the app should handle interactions, data receptions and deliveries, and overall control of the app.

# Provide instances in the full stack process when you refactored code to improve functionality and efficiencies, and name the benefits that come from reusable user interface (UI) components.
One instance of imporivng my code was transitioning my website from using static html pages to dynamic json driven pages using the express framework. This framework afforded me the ability to send and receive JSON which would eventually update the UI for customers while also ensuring separation of concenrs as the views now only focus on UI whereas the models and controllers can focus on data shaping and business logic. Another instance was the use of services such as the data service which again reinforced the separation of concern principle while ensuring we encapsulate the logic for db queries to prevent unauthorized access and create secure data transfers. This also allows us to create reusable UI components which saves time and money in development and maintenance while also improving user experiences through faster load times, easy navigation, etc.

# Methods for request and retrieval necessitate various types of API testing of endpoints, in addition to the difficulties of testing with added layers of security. Explain your understanding of methods, endpoints, and security in a full stack application.
API endpoints are the gateways which allow components within the app to communicate with one another. This is a popular design choice as again we focus on separation of concerns allowing our code to become more readable, maintainable, and testable. However, the threat of cybercrimes lingers over every app meaning I have to think about XSS, unauthorized access, and the potential for data theft. In this full-stack app, I focused on implemenitng a login process to authenticate admin users. Although this is a simple tactic to securing our app, it showcased the need for intentional and comprehensive testing. For instance, we tested our db API endpoint within the login process to ensure the backend received a JWT and that the JWT was verified and authorized. Implementing mulitple layers of security is beneficial, however, it makes the app's environment more complex forcing developers to manually test more often. These API endpoints and security measures are implemented via methods which get invoked as users attempt to interact with the application such as logging in, payments, etc.
